# API Design

## Planned Endpoints

### POST

```
/article
```

Create article.

---

### GET

```
/articles
```

Return all articles.

---

### POST

```
/connection
```

Create relationship.

---

### GET

```
/graph
```

Return graph.

---

### POST

```
/session
```

Create browsing session.

---

### GET

```
/sessions
```

Return all sessions.

---

### DELETE

```
/session/{id}
```

Delete session.
