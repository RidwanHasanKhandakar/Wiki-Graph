# Contributing

Thank you for your interest in contributing!

## Workflow

1. Fork the repository.
2. Create a feature branch.
3. Commit your changes.
4. Open a Pull Request.

## Coding Style

- TypeScript
- ESLint
- Meaningful commit messages
- Clear documentation

## Branch Naming

feature/<name>

bugfix/<name>

docs/<name>

## Commit Examples

feat: add graph renderer

fix: resolve duplicate node issue

docs: update architecture
